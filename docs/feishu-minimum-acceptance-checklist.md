# 飞书最小闭环验收清单

这份清单用于在 `Phase 5` 飞书官方接入闭环阶段，按最短路径确认：

1. 飞书官方插件准备链路可用
2. 机器人配置链路可用
3. 飞书配对码链路可用
4. 基础诊断入口可用于售后排查

## 1. 使用前提

- 已安装可运行的 `Mclaw` 包体
- 当前仓库或安装包内的 OpenClaw runtime 已命中：
  - `win32-x64 bundled-runtime`
  - 或 `darwin-arm64 bundled-runtime`
  - 或 `darwin-x64 bundled-runtime`
- 有一套真实可用的飞书测试凭证：
  - `App ID`
  - `App Secret`
- 有一个真实飞书账号，可用于：
  - 扫码
  - 给机器人发消息
  - 输入配对码

## 2. 最小闭环步骤

### A. 进入飞书接入页

- [ ] 可以进入 `ChannelConnect` 的飞书页签
- [ ] 可以看到：
  - `新建机器人`
  - `关联已有机器人`
- [ ] 页面没有明显历史品牌残留，如 `Qclaw` / `Qclaw Lite`

### B. 官方插件准备

任选一条路径即可：

#### 路径 1：新建机器人

- [ ] 点击 `新建机器人` 后，能进入官方安装器流程
- [ ] 页面能展示安装器输出
- [ ] 若安装器生成二维码，页面能展示真实二维码或可跳转的二维码链接

#### 路径 2：关联已有机器人

- [ ] 点击 `关联已有机器人` 后，页面能先检查飞书官方插件
- [ ] 若插件缺失，页面能自动补装或给出明确失败提示
- [ ] 插件准备完成后，页面能进入手动绑定区

### C. 完成机器人配置

- [ ] 飞书配置阶段的主按钮显示为：
  - `完成机器人配置`
- [ ] 完成后，页面日志或提示明确说明：
  - 机器人配置已完成
  - 下一步需要输入飞书配对码

### D. 获取并输入飞书配对码

- [ ] 在飞书里给机器人发送一条消息
- [ ] 能拿到配对码
- [ ] 页面成功进入下一步按钮：
  - `下一步：输入飞书配对码`
- [ ] 输入配对码后，可完成配对

### E. 基础可用性

- [ ] 配对成功后，机器人可收到消息
- [ ] 至少完成一次真实消息往返
- [ ] 渠道页 / 配对页不会把当前状态误报为未接入

## 3. 失败分流

### 插件准备失败

优先检查：

1. 是否能读取安装器输出
2. 是否有 `npx` / 网络 / 权限 问题
3. 页面是否提供了刷新状态或重试入口

### 手动绑定失败

优先检查：

1. `App ID / App Secret` 是否完整
2. 飞书凭证校验是否通过
3. 是否已进入 `关联已有机器人` 而不是 `新建机器人` 路径

### 配对失败

优先检查：

1. 是否真的给对应机器人发了消息
2. 当前输入的是否是最新配对码
3. 当前完成配置的机器人与发消息的机器人是否一致

## 4. 验收通过标准

满足以下条件即可判定“飞书最小闭环成立”：

1. 至少一条飞书路径可完成：
   - 新建机器人
   - 或关联已有机器人
2. `完成机器人配置` 后，可明确进入：
   - `下一步：输入飞书配对码`
3. 配对码可被成功输入并完成配对
4. 至少完成一次真实消息联通验证

## 5. 当前建议记录

每次真实验收后，至少记录：

- 验收日期
- 验收平台：
  - Windows
  - macOS Apple Silicon
  - macOS Intel
- 走的是哪条路径：
  - 新建机器人
  - 关联已有机器人
- 是否完成配对
- 是否完成真实消息往返
- 若失败，失败点停在：
  - 插件准备
  - 机器人配置
  - 配对码
  - 消息联通
