# 飞书联调结果记录模板

这份模板用于在执行飞书真实联调或验收后，快速回填结果。

建议配合：

- `docs/feishu-dual-path-field-record-sheet.md`
- `docs/feishu-minimum-acceptance-checklist.md`
- `docs/feishu-debug-triage-matrix.md`
- `docs/feishu-source-migration-strategy.md`

一起使用。

## 1. 基本信息

- 验收日期：
- 验收人：
- 验收平台：
  - Windows
  - macOS Apple Silicon
  - macOS Intel
- Mclaw 版本：
- OpenClaw 基线版本：
  - `2026.3.24`

## 2. 本次路径

- 本次走的接入路径：
  - 新建机器人
  - 关联已有机器人
- 飞书官方插件准备结果：
  - 已存在
  - 自动补装成功
  - 自动补装失败
- 是否完成机器人配置：
  - 是
  - 否

## 3. 配对结果

- 是否拿到飞书配对码：
  - 是
  - 否
- 是否成功进入：
  - `下一步：输入飞书配对码`
- 是否成功输入配对码：
  - 是
  - 否
- 是否配对成功：
  - 是
  - 否

## 4. 消息联通结果

- 是否完成至少一次真实消息发送：
  - 是
  - 否
- 是否收到机器人回复：
  - 是
  - 否
- 是否确认当前 Bot 与当前配置一致：
  - 是
  - 否

## 5. 失败点定位

- 若失败，卡在哪一步：
  - 官方插件准备
  - 机器人配置
  - 配对码获取
  - 配对码输入
  - 消息联通
- 页面提示内容：
- CLI / 安装器输出摘要：
- 是否可通过刷新状态恢复：
  - 是
  - 否

## 6. 结论

- 本次是否通过最小闭环验收：
  - 是
  - 否
- 若未通过，下一步建议：

## 7. 回填示例

可按以下格式回填到 `docs/dev_log.md`：

```md
飞书联调记录：

1. 验收平台：Windows
2. 接入路径：关联已有机器人
3. 官方插件准备结果：自动补装成功
4. 机器人配置：已完成
5. 飞书配对码：已获取并成功输入
6. 消息联通：已完成一次真实消息往返
7. 本次结论：通过飞书最小闭环验收
```
