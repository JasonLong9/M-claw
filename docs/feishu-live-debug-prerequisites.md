这份文档用于在开始飞书真实联调前，明确：

1. 你需要提前准备什么

3. 最短联调顺序是什么

## 1. 你需要提前准备的东西

开始真实联调前，建议至少准备以下内容。

### A. 飞书账号

- 一个可正常登录的真实飞书账号
- 该账号可以：
  - 手机扫码
  - 在飞书里给机器人发消息
  - 查看并输入配对码

### B. 机器人接入信息

如果你走“关联已有机器人”路径，需要提前准备：

- `App ID`
- `App Secret`

如果你走“新建机器人”路径，则不一定一开始就要手填这两个值，但仍建议准备好，便于失败时回退到手动绑定。

### C. 运行环境

- 一台可联网机器
- 当前机器可正常运行 `Mclaw`
- 当前安装包或仓库内 OpenClaw runtime 已命中：
  - `win32-x64 bundled-runtime`
  - 或 `darwin-arm64 bundled-runtime`
  - 或 `darwin-x64 bundled-runtime`

### D. 可选但建议准备

- `lark-cli`
  - 用于辅助判断飞书官方 CLI 的授权状态
  - 当前不是强依赖，但对诊断很有帮助

## 2. 从哪里进入

在当前产品里，最短联调入口是：

1. 打开 `Mclaw`
2. 进入 `连接 IM 渠道`
3. 切到 `飞书`
4. 选择以下两条路径之一：
   - `新建机器人`
   - `关联已有机器人`

## 3. 最短联调顺序

建议按下面顺序走，避免来回切换路径。

### 路径 1：优先推荐，先试“关联已有机器人”

适合你已经有：

- `App ID`
- `App Secret`

执行顺序：

1. 点击 `关联已有机器人`
2. 等待页面完成：
   - 官方插件检查
   - 自动补装或配置同步
3. 在手动绑定区输入：
   - `App ID`
   - `App Secret`
4. 点击 `完成机器人配置`
5. 页面进入：
   - `下一步：输入飞书配对码`
6. 去飞书里给机器人发一条消息
7. 获取配对码
8. 回到 `Mclaw` 输入飞书配对码
9. 完成一次真实消息往返

### 路径 2：如果要验证完整新建链路，再试“新建机器人”

执行顺序：

1. 点击 `新建机器人`
2. 等待安装器输出与二维码
3. 用手机飞书扫码
4. 在飞书侧完成机器人创建
5. 回到 `Mclaw` 点击 `完成机器人配置`
6. 页面进入：
   - `下一步：输入飞书配对码`
7. 去飞书里给机器人发一条消息
8. 获取配对码
9. 输入飞书配对码
10. 完成一次真实消息往返

## 4. 当前最建议你先提供给我的信息

如果你准备开始真实联调，最少告诉我以下几项是否已经具备：

1. 是否已有真实飞书测试账号
2. 是否已有可用的 `App ID / App Secret`
3. 这次准备先走哪条路径：
   - `新建机器人`
   - `关联已有机器人`
4. 联调平台是哪一个：
   - Windows
   - macOS Apple Silicon
   - macOS Intel

## 5. 联调时最常见的卡点

### 插件准备阶段

常见表现：

- 页面一直停在检查或安装阶段
- 刷新状态后仍不切换

优先检查：

1. 当前机器是否联网
2. 官方插件是否已落盘
3. 页面是否能看到安装器输出

### 手动绑定阶段

常见表现：

- `App ID / App Secret` 校验不过
- 机器人配置完成不了

优先检查：

1. 凭证是否完整
2. 当前填入的是不是目标机器人对应的凭证

### 配对阶段

常见表现：

- 没拿到配对码
- 输入后仍无法完成配对

优先检查：

1. 是否真的给当前机器人发了消息
2. 是否拿到的是最新配对码
3. 当前正在配对的机器人是否与刚才配置的是同一个
